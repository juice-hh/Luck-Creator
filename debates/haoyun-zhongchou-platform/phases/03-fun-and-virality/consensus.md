# 阶段 3 共识 · 有趣度与爆火潜力

> 2 轮辩论。第 1 轮 6 条必须回应在第 2 轮基本解决（1 条条件性、1 条情感层未完整承接）；新增 3 条带入 Phase 4/5。

## 已达成共识

1. **情绪陪伴与有趣爆火不互斥，但只在"轻玄学仪式 + 可截图好运卡 + 半匿名真人回声"这条线协同**。保留玄学梗/木鱼/泡泡/锦鲤作**纯视觉仪式包装**（点击动画/声音震动/抽签动效/卡片生成/当次完成感），**砍掉一切跨会话游戏化**（积分/排行/签到/解锁/稀缺/等级/攀比）。砍荒诞感与可晒卡片则传播货币不足。

2. **内容生产 = 四层机制**：① **授权真人"过来人"档案库**（主干，经本人同意的历史留言、明确标注"历史/非实时"、单节点 80-150 条）② 模板引导 UGC（半成品句式降产出成本）③ LLM 只做非真人层（签语/卡面/去隐私改写，签语模板化短句化、避具体承诺，**绝不冒充真人回声**）④ 节点前小规模人工精选。**承认内容质量有天花板**，只做 2-3 个节点（考试/秋招/新年），不做全年通用社区。

3. **焦虑峰值"即时被接住" = 三段式**：0 秒自我仪式兜底 + 私密好运卡 → 5 秒真人历史档案回声（明确标注"历史/已授权/非实时"）→ 异步活人回声（有则有、没有不假装）。基础体验不依赖实时真人。

4. **隐私 × 传播 = 双层卡面**：可晒版（默认，只露签语 + 节点标签 + 氛围数据 + 用户单填的"可公开一句"，不露完整心愿）/ 私享版（仅自己看，完整心愿 + 回声）。写心愿分"私密愿望"+"可公开一句"两栏。

5. **诚实结论：不具备长期全民爆火条件，是"节点型传播产品"**。传播货币 = 可截图好运卡（自嘲型/玄学型/被接住型），中等偏强。能爆的瞬间是"我也在这个节点求一点好运"的截图共鸣，不是平台社交网络效应。爆火不是北极星，节点爆发更现实。

## 开放张力（带入后续）
- **N-B1（命门，→Phase 4）上线前 80-150 条授权优质留言怎么搞到**：无社区/无激励/无法务，授权获取+优质筛选(可能需收 300-500 条原始)是冷启动前置，前提不成立则整个冷启动解法坍塌。
- **N-U2（产品身份，→Phase 5 拍板）核心情感定位**："此刻有人陪你"还是"你不孤单，曾经有人和你一样"？决定文案/标注/期望校准，需明确定位。
- **N-U1（→Phase 4）档案库复用祛魅临界点**：高频用户约 8-12 次访问后重复感→被陪伴感不可逆质变，须确保在祛魅前已产生传播/价值。
- **N-B2（→Phase 4）节点间衰减/召回**：无召回则"周期性归零重建"非累积增长。
- **N-U3** 两栏填写峰值摩擦（原型验证完成率）；**氛围数字**冷启动期反向信号展示策略。
