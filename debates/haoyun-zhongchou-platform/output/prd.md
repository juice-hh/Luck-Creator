# 好运池 / 心愿池 — 产品需求文档（PRD）

> 由 5 阶段跨模型对抗辩论收敛而成（GPT-5.4 提案 / Claude 双视角审查）。本 PRD 描述"做什么、为什么"，不含技术实现与排期。
> ⚠️ 本 PRD 是对原"游戏化好运众筹平台"设想的**重大重定位结论**，落地前需用户确认（见末尾）。

## 1. 一句话定位

**好运池 / 心愿池**：一个在人生节点里**先接住你此刻**、再让你知道**不是只有你这样**的、零金钱、半匿名、轻盈而克制的情绪慰藉小产品。

- 不是"众筹平台"（"众筹"暗示钱/目标/进度/达成，会误导）。
- 不是增长型社交平台，也不是高频日活工具。
- 是一个适合个人长期维护、气质独特的"节点型情绪器物"。

## 2. 为什么做（问题与需求）

- 人在不确定事件前（考试、面试、失恋、等结果、低谷夜）需要一个**低成本、低羞耻、可重复的心理安放动作**。这是真需求，但是**事件驱动的低频情绪需求**，不是高频刚需。
- 现状替代品各有缺口：电子木鱼只有自我安慰无回应；求转发锦鲤有社交负担且打扰朋友；烧香拜佛成本高不即时；树洞/匿名社区易情绪泛滥。
- 不可替代点 = **半匿名祝福"场域"**：无需金钱、无需熟人暴露、无需强转发——补的是微信/小红书做不了的"我想要点回应，但不想真的求任何具体的人"。

## 3. 目标用户与场景

- 用户：有情绪压力、需要心理寄托的年轻人（考试/求职/情感/健康焦虑场景）。
- 核心场景（V0 先打 1 个）：考前、失恋/告别后、焦虑、等消息、想被祝福、说不清。
- 使用姿态：焦虑高峰时打开一次（30 秒级），而非每天来。

## 4. 核心设计原则（不可妥协）

1. **零金钱**：信任基础，永不做付费转运/曝光/加速/广告。
2. **零焦虑**：无 deadline、无签到/连胜、无倒计时、无过期失败、无"必须拉人"。
3. **不伪造真人**：LLM 生成内容明确标注非真人；空池诚实呈现，不假装热闹。
4. **先接住此刻，再谈共鸣**：第一动作是即时承接（30 秒内出卡），"曾经有人和你一样"为第二层。
5. **有趣但不轻佻**：纳入"体验游戏化"（好笑福气卡/轻盈语气/可截图视觉）作为不靠机制的传播钩子；坚决砍"机制游戏化"（积分/连签/排行/抽卡/数值/任务）。
6. **小而诚实**：个人项目尺度，先验证再投入，有明确止损线。

## 5. 体验框架

### 5.1 V0（最小可验证实验，2-4 周）—— 「此刻福气卡」
目标：用最小成本验证"轻盈、有趣、可晒的情绪卡，在脆弱场景里是否仍被认为可信、能承接、愿分享"。

流程：
1. 进入页面，选一个状态（考前 / 失恋 / 焦虑 / 等消息 / 想被祝福 / 说不清）。
2. 写一句"我现在希望……"。
3. 生成一张**可截图双层卡**：表层轻盈福气文案，里层一句更稳的承接话。
4. 可截图 / 复制链接 / 再抽一张。**无积分、无连签、无排行、无档案库、无 UGC 池。**
5. 祝福先用 LLM 生成（标注非真人）。同时 A/B 三种语气：温柔型 / 轻幽默型 / 签语型。

文案示例（语气样本）：
- "今天先不求逆天改命，先求你能吃上一口热饭。"
- "这张好运不负责包赢，但负责陪你撑过这一小时。"
- "愿你的破事排队等明天处理，今晚先放你一马。"

V0 验证指标：完成率（进入→生成卡）/ 保存截图意愿 / 主观承接感（"有没有让你稍微好一点"）/ 信任风险（是否油腻/假/冒犯/像骗钱）/ 分享质量（非奖励驱动的自然转发）。

### 5.2 V1（仅当 V0 验证成立才做）
- 2-3 个情绪节点（急性脆弱 / 轻度低落 / 许愿祝福）。
- 三段式承接：**此刻接住 → 轻盈福气卡 → 可选"曾经有人也这样"**。
- 双层卡面：外层可晒（签语+节点标签+氛围+"可公开一句"）、内层私享（完整心愿+回声）。
- 半匿名祝福池（异步时间窗池）：可给同主题历史/未来有效心愿送好运、异步收到；**空池不伪造真人**，回自我仪式兜底。祝福供给靠"结束节点（我过了/先放下）"峰值即时贡献 + 授权过来人档案 + 模板 UGC + 人工精选 + LLM 非真人签语。
- 可截图分享视觉系统（增长钩子，但不绑奖励）。
- 基础安全边界：危机词触发"建议寻求现实帮助"，不做心理治疗承诺。

### 5.3 明确不做（V0/V1 都砍）
金钱化/众筹化/付费转运；双货币/积分/等级/排行；连签/任务/抽卡概率/稀缺；强社交关系链/关注/私信/评论区；伪造真人祝福；全民爆款增长叙事；太多节点；时间轴手账（节点低频，价值近零、成本错配）。

## 6. 增长与留存（诚实版）

- **没有强增长引擎**。增长靠：内容本身的传播价值（可晒福气卡）+ 节点后留存 + 缓慢口碑 + 作者手动拉种子。现实天花板：小圈层（6 个月几百到一两千访问量级）。
- 留存靠情感而非机制：福气回声（只显"被收下/被读到"的抵达感）+ 三类**健康召回**（回声召回 / 用户自设约定 / 季节节点 4-6 次/年）。**绝不 daily push / streak / "X天没来" / "好运快过期"。**

## 7. 商业化

- **V0/V1 不变现**。零金钱是信任基础。
- 若未来必须：仅作者自费/开源/无标识小额托管；明确不做付费祈福、广告、早期机构合作（金主改气质）、周边（用户群断裂）。

## 8. 运营现实（MVO）

- 最小可运营状态 = **作者每周 2 小时**（审核新内容 + 匿名化 + 入池 + 查异常），不维护社群、不每日运营。
- **止损判据**：连续 6 周每周新增有效内容<2 条 / 关键转化持续低于阈值 / 作者负担明显 / 反馈集中"像签语没差异"——出现 ≥3 项即承认 fallback 是终点，保留为个人作品或停。

## 9. 关键风险与赌注

- 做了会后悔：以平台心态做却无增长无变现、维护成本持续；做太像众筹被误解；为活跃加机制破坏可信；LLM 滥用变廉价鸡汤；节点铺太多每池空。
- 不做会后悔：适合个人长期维护的独特小作品；可能成为少数人关键时刻真记住的工具；"结束节点贡献给后来人"温柔且成立；作为作品集展示罕见取舍能力。

## 10. 落地前需用户确认的方向性决策

1. **接受重定位**：从"游戏化好运众筹"→"好运池/心愿池：此刻福气卡"（弃"众筹"名、砍虚拟双货币、砍机制游戏化但保留有趣体验）。
2. **接受"先做 2-4 周 V0、用数据决定是否投 V1"** 的路径，而非直接做完整版。
3. **首发场景**选哪个（建议考前或失恋/告别）。
4. **情感定位**采用"先接住此刻，再让你知道不是只有你这样"。
