# 核心承诺（回溯锚点）

> 各阶段提取的已确认承诺。后续阶段的提案必须与之一致，如需推翻须显式论证。

## Phase 1 · 需求与定位

- **C1.1** 产品定位为"匿名低压表达 + 轻量真实回应 + 自我仪式兜底"的**情绪产品**，不是"众筹平台"。（注：原名/双货币的去留见张力 T1/T2，待用户拍板）
- **C1.2** 需求是**事件驱动、焦虑高峰才打开的低频情绪需求**，不按日活工具设计。
- **C1.3** 不可替代点是**半匿名祝福"场域"**（无金钱/无熟人暴露/无强转发）；场域感做不出则产品不成立。
- **C1.4** **0 回应必须用自我仪式兜底，绝不用系统/机器人冒充真人祝福**；第一次心愿的成功反馈必须由用户自己完成。
- **C1.5** 冷启动只能靠**真人小种子池 + 单一主题池**（限时窗口、不用机器人）；MVP 只验证"愿否发心愿 / 愿否送好运 / 少量真实回应下愿否回访"三件事。

## Phase 2 · 核心机制

- **C2.1** 砍掉可见双货币经济/兑换链，改"**双反馈**"：好运卡（仪式结果物，人人得）+ 福气回声（他人真实祝福痕迹，只增强不作资源）；积福值退为后台不可见信号。
- **C2.2** 给予靠**情感驱动**（同境共情 + 极低成本 + 异步轻互惠），不靠积分/兑换/排行/稀缺。
- **C2.3** 留存 = 事件周期内自然回访，**明确放弃日活/签到**。
- **C2.4** 社交是主菜但形态 = 嵌入个人结果页的"回声"，广场为二级。默认路径：选主题→写心愿→仪式→好运卡→卡底同主题回声→可选送好运→可选回声池。
- **C2.5** 广场 = **异步时间窗池**（可给历史/未来有效心愿送好运、异步收到）；空池不伪造真人、回自我仪式兜底。
- **C2.6** 有一组带阈值的 MVP 预警指标；种子用户不被安排任务式互动。

## Phase 3 · 有趣度与爆火潜力

- **C3.1** 保留玄学梗/木鱼/泡泡/锦鲤作**纯视觉仪式包装**，无任何跨会话游戏化（积分/排行/签到/解锁/稀缺/等级）。
- **C3.2** 内容 = 四层机制（授权真人档案库主干 + 模板引导 UGC + LLM 仅非真人签语/卡面 + 节点前人工精选）；质量有天花板；只做 2-3 个节点，不做全年通用社区。
- **C3.3** 焦虑峰值即时被接住 = 三段式（自我仪式兜底 + 授权历史档案回声[标注非实时] + 异步活人回声可选）。
- **C3.4** 双层卡面（可晒/私享）+ 写心愿分"私密愿望/可公开一句"。
- **C3.5** 诚实定位：节点型传播产品，不具备全民爆火条件；传播货币 = 可截图好运卡。

## Phase 4 · 冷启动与增长

- **C4.1** 两级启动（<15 静态原型 / 15-20 封闭内测 / 40+ 公开试运行）；授权档案来源以熟人+自招募为主，陌生私信仅补充（转化 3-5%、有封号风险）。
- **C4.2** 档案续充靠"结束节点（我过了/先放下）"峰值即时贡献，不靠冷回流；更新速率低（月增个位数）。
- **C4.3** **诚实结论：无强增长引擎**。好运卡是弱传播/内容贡献非病毒链。现实定位=慢、小、靠作者维持的节点慰藉库，天花板=小圈层（6 个月几百到一两千访问）。
- **C4.4** 留存=福气回声（只显抵达感）+ 时间轴/事件触发手账 + 三类健康召回；绝不 daily push/streak。
- **C4.5** MVO=每周 2 小时可维持（最小状态不死但停增长）；有明确止损判据（≥3 项信号则承认 fallback 是终点）。

## Phase 5 · 商业可持续与最终取舍（终局）

- **C5.1** V0/V1 不变现，零金钱是信任基础；早期最多作者自费，不做付费转运/广告/早期机构/周边。
- **C5.2 中间路线**：纳入**体验游戏化**（好笑福气卡/轻盈语气/可截图视觉=传播钩子），继续砍**机制游戏化**（连签/积分/排行/抽卡/运势数值/任务/付费）。修订 C3 的"砍游戏化"边界（之前砍过头）。
- **C5.3 最终判断：有条件地该做**——先 2-4 周 V0 验证，达标（脆弱时刻愿打开 + 觉得被接住 + 自然分享）才投 V1，否则止损。不空切"个人作品"标准、用 V0 数据决定（收束 T5）。
- **C5.4 V0 =「此刻福气卡」**：选状态→写一句→生成可截图双层卡→无机制无档案无 UGC（LLM 祝福源，不冒充真人）；2-4 周小流量验证 + 三种语气 A/B。
- **C5.5 T4 定位 = "先接住此刻，再让你知道不是只有你这样"**；急性承接为第一层，"曾经有人和你一样"为第二层。
- **C5.6 安全边界**：危机词提醒寻求现实帮助，不做心理治疗承诺。
- **T1/T2 收束**：彻底砍双货币（只留好运卡+福气回声）；重定位"好运池/心愿池"，弃"众筹"名。

## 已收束的张力（原待拍板项 → 辩论结论）
- T1 砍双货币 ✅；T2 重定位好运池/心愿池 ✅；T3 密度先 LLM 兜底、真人池二阶段 ✅；T4 见 C5.5 ✅；T5 用 V0 验证决定、不空切标准 ✅。
> 注：以上为辩论结论，仍需用户最终认可（尤其是从"游戏化好运众筹"到"好运池/此刻福气卡"的重大重定位）。

## 待用户拍板的方向性张力（非承诺）
- **T1** 砍掉双货币 —— 辩论结论=砍（改双反馈），但与 spec 骨架冲突，**请用户最终确认**。
- **T2** 是否接受从"好运众筹"重定位为"好运池/心愿池"。
- **T3（根本性）** 砍掉奖励后，**情感驱动能否独立支撑给予与池密度**（NB-2）——Phase 4/5 深辩，"产品是否成立"的命门。
- **T4（产品身份）** 核心情感定位是"**此刻有人陪你**"还是"**你不孤单，曾经有人和你一样**"（N-U2）——决定文案/标注/期望校准，Phase 5 拍板。
- **T5（决定性）判断标准** 以"商业化平台"衡量大概率不值得做；以"个人长期小作品/公益工具"衡量可做小验证——Phase 5 先定标准再下结论。
